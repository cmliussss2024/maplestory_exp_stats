# 桌面小块采集：可行性与检测面

> **状态（已落地）**：主路径已是桌面小块 mss + 多屏漏斗；`window_capture` / 绑窗 WGC / 按标题找窗已从运行时去掉。下文保留为改前评估与目标链路说明。

对照见 [测谎风险评估](lie-detector-assessment.md)。改前主路径是对冒险岛 HWND 做 `CreateForWindow`，锁定后仍每秒整窗出帧，再在内存里裁经验条。

拟改（现已实现）：不再采集游戏进程；坐标系用虚拟桌面；锁定后只拷已经定位的那一小块；只有采不到时，才 3 秒一次多屏漏斗匹配。

## 结论

能做成。这三条打掉的是评估里最强的那条指纹：绑游戏窗口的 Graphics Capture。

检测面会从「有进程在抓冒险岛 HWND」变成「偶尔拷桌面小块」。不再对游戏窗口建采集会话、不再按标题找「冒险岛」、不再每秒整窗出帧。从客户端看，不再干涉冒险岛窗口——对这条采集面成立。

小块 BitBlt 仍是截屏 API，只是对象是桌面合成结果，不点名游戏进程。置顶分层 HUD 这次不动。测谎是服务端判定，改完不能保证不再弹；能说明的是这条采集面比现在轻。

## 三条能否落地

| 方向 | 能否做 | 说明 |
| --- | --- | --- |
| 1. 不采集游戏进程，范围改桌面 | 能 | 关掉 `create_for_window`。坐标系是桌面，每秒并不拷整张桌面。 |
| 2. 锁定后每秒只截已定位的那一小块 | 能 | `locked_rect` 已是虚拟屏坐标；mss 按矩形抓。经验条约 `172×37`（再乘 DPI）。`grab_region` 只走小块 mss。 |
| 3. 采不到时才 3 秒一次多屏漏斗匹配 | 能 | 状态机：锁定约连续 10 秒读不到 → 重新定位，搜索间隔 3 秒。搜索走物理屏 `monitors[1..n]`，不用 `monitors[0]` 外接大图。 |

「采集但不整屏截图」：锁定路径只 BitBlt 小矩形。多屏搜索只在丢锁 / 冷启动时出现。

## 目标链路

```
监控中（1s）：mss 只抓 locked_rect → OCR
    └ 标签约连续 10 秒不在 → 重新定位（保留 last_rect / 上次屏）
定位中 / 重新定位（3s）：
    1. 隐藏自身经验条预览（Canvas 高度不变）→ 刷屏
    2. 若有 last_rect：邻域（约 ±300px）匹配 ← 多数情况（商城/切屏/短暂黑屏）
    3. 逐物理屏（上次命中屏优先）：底带 30% → 未命中再搜该屏上半 70%
    4. 命中 → 写下 locked_rect + 记下屏索引；按该屏 DPI 短名单尺度匹配
失败 20 次 → 读取失败（现有逻辑）
```

复用进程内长寿命 mss 实例。不上 DXGI / GPU 匹配。防预览误匹配靠搜前藏图，不靠从位图扣自身窗口矩形。

不再：`EnumWindows` 找冒险岛、`CreateForWindow`、整窗 GPU 纹理、关采集黄框。

## 会换掉什么

| 去掉 | 还在 |
| --- | --- |
| 绑游戏 HWND 的 WGC | 小块桌面 BitBlt（通用截屏，不点名冒险岛） |
| 每秒整窗出帧 | 3 秒一次多屏漏斗，且仅在丢锁 / 冷启动 |
| 按标题找「冒险岛」窗口 | 置顶窗 / 分层 HUD |

代价：游戏被挡住时读到的是挡住它的像素；独占全屏若没进 DWM，小块可能是黑的（当前窗口模式可用）。短暂遮挡后优先邻域重锁；拖到别的屏或冷启动才走底带 / 同屏回退。

## 实现顺序

1. `grab_region` 只走小块 mss，去掉每秒整窗；复用 mss。
2. 搜索改多屏漏斗（邻域优先 → 底带 → 同屏上半），搜前藏预览；按屏 DPI 短名单。
3. 删除 `window_capture` 的 `CreateForWindow` 路径与运行时按标题找窗。
